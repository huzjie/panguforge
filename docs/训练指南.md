# 训练指南

## 三个阶段

### 1. 预训练（pretrain）

语言建模目标：最小化下一 token 的交叉熵。

```bash
python -m panguforge pretrain --config examples/config_pretrain.yaml
```

- `train.steps`：训练步数
- `mock.skill_init`：初始 skill（越低初始 loss 越高，学习空间越大）
- `mock.lr`：skill 更新步长

### 2. SFT（监督微调）

在指令 - 响应对上微调，让模型遵循指令格式。

```bash
python -m panguforge sft --config examples/config_sft.yaml
```

### 3. RL 后训练（GRPO / PPO）

```bash
python -m panguforge rl --config examples/config_rl.yaml
```

- `rl.algorithm`：`grpo`（组相对策略优化）或 `ppo`（近端策略优化）
- `rl.steps`：迭代轮数
- GRPO 对每个 prompt 采样一组 K 个回答，按组内相对优势更新策略

## 学习率与优化器

- `train/optimizer.py`：SGD、AdamW
- `train/lr_scheduler.py`：Constant、CosineDecay（含 warmup）

## 检查点

`Checkpointer` 把状态保存为 JSON（`checkpoints/` 目录），支持 `save` / `load`。

## 回调

- `MetricLogger`：按 `log_every` 打印指标
- `EarlyStopping`：按指标早停

## 观察指标

| 指标 | 含义 |
|---|---|
| `loss` | 负对数似然，训练中应单调下降 |
| `skill` | 正确下一 token 概率，训练中应单调趋 1 |
| `acc` | 准确率（约等于 skill） |
| `reward` | RL 平均奖励，应单调上升 |
