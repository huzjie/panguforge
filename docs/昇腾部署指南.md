# 昇腾（Ascend）部署指南

openPangu-2.0 主打「昇腾原生训练与推理」。panguforge 通过 `backends/ascend.py` 定义昇腾原生契约。

## 后端接口

```python
from panguforge.config import load_config
from panguforge.backends import get_backend

cfg = load_config("config.example.yaml")
cfg["backend"] = "ascend"
engine = get_backend("ascend", cfg)
print(engine.status())   # {"backend": "ascend", "available": ...}
```

## 可用性探测

后端按以下顺序探测 NPU 环境：

1. 环境变量 `ASCEND_HOME` / `ASCEND_TOOLKIT_HOME`
2. `torch_npu` 可导入

无 NPU 时 `available=False`，调用训练会明确报错并提示回退 `mock` / `cpu`。

## 接入真实 NPU

真实昇腾训练请对接：

- **CANN**：`ASCEND_HOME` 指向 CANN 安装目录
- **torch-npu**：`pip install torch-npu` 后按 `torch_npu` 迁移
- **MindSpore**：MindSpore Ascend 后端

## 环境变量

| 变量 | 说明 |
|---|---|
| `ASCEND_HOME` | CANN 工具链根目录 |
| `ASCEND_VISIBLE_DEVICES` | 可见 NPU 编号 |

## 说明

- 本仓库的 `ascend` 后端是**接口契约与探测实现**，不含华为官方 CANN/torch-npu 依赖。
- 核心训练/推理用 mock / cpu 后端即可零依赖跑通；昇腾原生大规模训练由用户在真实 NPU 环境按官方 openPangu-2.0 代码落地。
