# 快速开始

## 环境要求

- Python 3.9+
- （可选）PyYAML，用于读取 `.yaml` 配置；未安装时自动回退内置极简解析器

## 安装

```bash
git clone https://github.com/huzjie/panguforge.git
cd panguforge
pip install -e .
```

## 体检

```bash
python -m panguforge doctor --config config.example.yaml
```

应输出所有后端的可用性检查结果。

## 一键全流程

```bash
python examples/quickstart.py
```

依次执行预训练 → SFT → RL → 生成，输出 loss 下降与 skill 上升的完整过程。

## 分步执行

```bash
# 预训练
python -m panguforge pretrain --config examples/config_pretrain.yaml

# SFT
python -m panguforge sft --config examples/config_sft.yaml

# RL 后训练（GRPO）
python -m panguforge rl --config examples/config_rl.yaml

# 基准
python -m panguforge bench --config config.example.yaml

# 推理服务
python -m panguforge serve --config config.example.yaml --port 8000
```

## 服务调用

```bash
curl http://127.0.0.1:8000/health
curl http://127.0.0.1:8000/v1/completions -H "Content-Type: application/json" \
     -d '{"prompt":"你好","max_tokens":16}'
curl http://127.0.0.1:8000/v1/chat/completions -H "Content-Type: application/json" \
     -d '{"messages":[{"role":"user","content":"介绍一下 MoE"}]}'
```

## Docker

```bash
docker build -t panguforge .
docker run -p 8000:8000 panguforge
# 或
docker compose up
```

## Kubernetes / Helm

```bash
kubectl apply -f deploy/k8s/
helm install panguforge deploy/helm
```
